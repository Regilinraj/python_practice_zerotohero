# Day 05: Lists and Tuples

- List: ordered, changeable. Tuple: ordered, NOT changeable
- Index starts at 0, last item is [-1]
- Slicing [start:stop:step], stop is excluded
- append (one), extend (many), insert (position)
- remove (by value), pop (by position), del
- sort() changes the list, sorted() returns a new one
- sum, min, max, len
- b = a is NOT a copy, use a.copy()
- List comprehension: [x for x in items if condition]
- Unpacking: a, b = (1, 2)
