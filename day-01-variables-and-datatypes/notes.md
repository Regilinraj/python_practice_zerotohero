# Day 01: Variables and Data Types

- Variable = labelled box storing a value
- Types: str, int, float, bool, None
- type() shows the type
- f-string: f"Price is {price}"
- Convert with int(), float(), str()
- Names: snake_case, no spaces, cannot start with a number

# Day 02: Input, Output and Operators

- print(sep=, end=), \n and \t
- input() always returns str, so convert with int() or float()
- Arithmetic: + - * / // % **
- Comparison: == != > < >= <= (result is True/False)
- Logical: and, or, not
- Assignment: += -= *= /=
- f"{value:.2f}" gives 2 decimal places
- = stores, == compares
