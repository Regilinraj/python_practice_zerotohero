# Day 04: Loops

- for item in collection: runs once per item
- while condition: repeats until False (watch for infinite loops, Ctrl+C)
- range(start, stop, step), the stop value is excluded
- break stops the loop, continue skips one round
- enumerate gives index and item, zip pairs two lists
- for...else: else runs only if no break happened
- Running total: total = 0 BEFORE the loop, total += x inside
- Nested loop: loop inside a loop
